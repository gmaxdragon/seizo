SEIZO AXIAL ROLL AND LEARNING v6

Use your existing START_SEIZO.bat. No new folder is needed.
STOP & save the current run, wait for saving, close its terminal, and reopen the
same starter with internet. The page should show seizo-roll-learning-v6.

1. Gripper check -> Tool roll 0 to 360 degrees -> Check gripper.
   The whole hand rolls around the axis pointing toward its fingertips, not
   left/right like a steering joint. Opening stays independent.
2. Open / close with no object: no finger contact should be reported.
3. Contact squeeze: the explicitly fixed diagnostic block resists closing.
4. Hold free block + roll 90 degrees: a pre-positioned free block is held by
   real simulated contacts, rolled, and released. This is a SCRIPTED MECHANISM
   CHECK, not learned pickup or a demonstration used to train the network.
5. Test all tasks: seven separate frozen-policy tests, paired with random actions
   on fresh scenarios. Settings chooses 5, 20 or 100 trials per task. Stopping
   cancels the test rather than calling a partial run a pass.
6. Train / resume: Automatic lessons starts with reach and progresses after
   held-out validation improves, reviewing older tasks along the way. Updates,
   episodes and movement decisions are separate counters. Watch policy does not
   update weights. Failed attempts remain failures.
7. Optional: Ask AI about my test results sends one compact numeric evaluation
   summary to Hack Club. The response can suggest a lesson; Use suggested lesson
   only selects the task. You still press Train. No cloud fine-tuning occurs.

The API counter reports actual manual requests, accepted responses and reported
usage. LOCAL PPO TRAINING USES ZERO API CALLS. The API key and Windows DPAPI storage
are unchanged. No key is included in this download, logs or GitHub.

360-degree roll here is a SIMULATION setting based on your description. It is
not confirmation of the physical motor's feedback, range, cable limits or servo
protocol. No Pi, GPIO, serial, real-motor commands or Railway changes were added.
Old v5 policies are archived byte-for-byte and cannot silently drive this v6 model.
